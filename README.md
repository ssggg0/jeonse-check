# 전세체크 — 부동산 매물 위험도 통합 스캐너 (MVP)

매매가·보증금·근저당만 넣으면 깡통전세 비율과 HUG 전세보증금반환보증 가입 한도를 즉시 계산하는 모바일 웹 프로토타입.

- 3초 신호등 결론 카드 (🟢 계약 OK / 🟡 주의 필요 / 🔴 위험 · 계약 재고 + 위험비율·보증보험 가능여부 2개 수치)
- 3칸 입력 (집값·보증금·집주인 대출) + 실시간 한글 금액 환산, 공시가격·신탁·위반건축물·용도는 접힌 '상세 조건 추가'
- 계약서 필수 특약 3줄 원클릭 복사 (위험 요소별 자동 선택)
- 근거는 접기 카드로 (HUG 한도 계산 · 감점 사유 · 등기부 체크 10)
- 9,900원 상세 리포트 신청 모달 (베타 기간 무료)

단일 `index.html` · 390px 최적화 · 외부 라이브러리 0개 · 화이트+네이비 핀테크 톤.
